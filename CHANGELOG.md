# Changelog

## Unreleased — Evidence Replay: cinematic graph navigation with voice

- **The signature feature**: ask a question in the floating bar above the knowledge graph, press Replay, and watch the evidence trail unfold. The camera zooms to the primary evidence node — it glows, the connecting edge lights up, the glow travels to the next node, and a voice guide narrates each step. Playback controls: play/pause, previous/next, speed (0.5×/1×/2×), timeline scrubber. Previously visited nodes keep a subtle trail glow so the full path stays visible. The replay ends with a verdict.
- **Honest by construction**: every step comes from the actual retrieval trail (ranked memories, graph-path edges, verified code links) — `POST /v1/replay` → `intentgraph/replay.py` → `generate_replay()` — never an invented narrative. If evidence is insufficient, the replay says so.
- **Zero-dependency voice**: uses the browser's built-in `speechSynthesis` API — no API keys, no external services. Narration also displays as a subtitle for accessibility and when speech is muted.
- **Injected into every graph view**: the replay engine (`intentgraph/frontend/replay.js`) is embedded into the memory-code, memory, and code graph HTML alongside the view-switcher. Steps whose nodes aren't in the current view are skipped honestly.
- **Visual language**: the focal node glows purple (`#827AFF`), the active evidence path glows mint (`#59E8C7`), the trail dimms to a subdued teal. The contrast between the active route and the surrounding graph makes the journey understandable.
- Tests: +4 (replay returns ordered steps with the focal node first and verdict last, honest empty-state, query validation, the engine is present in the graph HTML). Suite: 538 pass / 5 live-gated; ruff + pyright clean; wheel builds.

## Unreleased — cross-graph milestone: evidence-linked memory ↔ code

- **Code links (store schema v2, additive)**: a `code_links` table wires memory records to code-graph nodes in three verification tiers — `explicit` (`codelink add`, validated against the graph), `extracted` (deterministic text matcher over the record's own backticked/dotted/file-path references; auto-runs at ingest, `codelink refresh` recomputes the tier and removes stale matches), `candidate` (`codelink suggest`, semantic similarity, dry-run by default, labelled and never followed as retrieval evidence). Links are stored separately from record content — code-graph rebuilds never rewrite historical evidence; purge cascades; export/import round-trips them (older v1 bundles still import; newer bundles are refused clearly).
- **Cross-graph retrieval** (`intentgraph.query` / `intentgraph query` / `recall` tool's optional `include_code` flag): one question returns memories (unchanged hybrid), code entities (deterministic `CodeIndex` symbol/path search with bounded expansion), and verified-link traversal in both directions — every entry carrying source paths, line numbers, memory ids, and link provenance. Controls: `top_k`, `code_top_k`, `depth`, `budget_tokens` (deterministic tail trimming, reported). No code graph → memory retrieval unchanged, plus an honest note.
- **CLI**: `query`, `codelink add|list|remove|refresh|suggest`, `codegraph search` (deterministic symbol/file search), `viz --with-code`; `_open` auto-wires `codegraph-out/graph.json` from the working directory (same policy as the MCP sessions).
- **Bridge**: verified code links join the anchor index (`index_code_links`), so linked records participate in code-adjacency retrieval; fresh links/anchors register incrementally at ingest (`add_anchor`). Performance fix found by measurement: the bounded BFS now returns hop distances itself, replacing a per-pair `shortest_path_length` that made bridge expansion quadratic on real-size graphs — combined-repo renders went from ~63 s to ~1.3 s with identical scores.
- **Visualization**: the combined render (`viz --with-code`) shows memory records + code entities (typed shapes) + their links — verified green, candidate dashed gray — and retrieval highlighting covers only what the query actually returned.
- **Engine hardening**: symbol nodes carry their dotted `qualname` (additive schema-v1 field); `write_json` is atomic (temp + rename — a failed rebuild cannot corrupt a valid graph).
- **Semantics**: bare single words never auto-link; candidate suggestions exclude already-verified pairs; embedding similarity is never treated as proof.
- Tests: 39 new (link store, explicit/extracted/candidate tiers, deterministic search, the full end-to-end "why does this exist" scenario with its negative control, MCP surface, combined viz, CLI). Suite: 517 pass / 5 live-gated; ruff + pyright clean.

## Unreleased — native codebase graphs (the codegraph engine)

- **`intentgraph/codegraph/`** (new): IntentGraph's own code-graph engine, written from first principles (stdlib `ast` + networkx — no external code-graph engine installed, imported, or used). Pipeline: scan → parse → index → resolve → build → analyze → export. **Python only** (stated honestly everywhere); a `LanguageParser` protocol + `PARSERS` registry is the extension point for other languages.
- Evidence discipline: nodes typed `repository`/`directory`/`module`/`test`/`class`/`function`/`method`; edges `contains`/`defines`/`imports`/`calls`/`inherits`/`references`/`tests` with EXTRACTED vs INFERRED confidence, source file/line provenance, and merged evidence locations. External and statically unresolvable relationships are per-node metadata (`imports_external`, `imports_unresolved`) and counters — never invented edges. The internal graph is a relation-keyed MultiDiGraph, so parallel relations between the same pair never collapse.
- Determinism: sorted scans; path-derived stable ids matching the bridge's documented anchor scheme (verified string-equal against the legacy engine's ids for surviving files, so existing `graph_anchors` keep resolving); deterministic `__2` collision suffixing; byte-identical exports for identical trees. `.gitignore` practical subset (incl. `!` negation), built-in excludes (venvs, caches, build output, memory archives), secret-like files never read, symlinks never followed, size/count limits with explicit truncation reporting.
- Exports: `codegraph-out/graph.json` (node-link, schema-versioned `intentgraph-codegraph` v1, per-link `_src`/`_tgt` direction markers, renderer-ready fields) and GraphML. Legacy marker-less files stay valid; files from a newer schema version are refused with a clear error — never silently reinterpreted.
- CLI: `intentgraph codegraph build|refresh|stats|show|path|render` (options: `--output --exclude --include-tests/--no-include-tests --max-files --max-file-size --format json|graphml --html --verbose`); `update --anchors` attaches memories to code nodes without rewriting content.
- Integration: the bridge auto-wires `codegraph-out/graph.json` first (legacy `graphify-out/` fallback) and reports the loaded graph's schema; the renderer accepts an optional `lexicon` so code graphs render with code wording (the memory-graph default render is byte-identical to before).
- Analysis: graph stats, bounded import cycles, hubs, direction-aware orphan candidates (dunder methods and test symbols excluded by policy — candidates, not proven dead code), deterministic shortest paths with edge relations, bounded neighborhoods, connected components.
- Tests: 55 new tests covering extraction fidelity, ids/determinism, ignores/secrets/symlinks/limits, cycles/paths/orphans, empty repositories, bridge+renderer+memory integration, CLI behavior, and a clean-interpreter proof that the engine builds graphs with Graphify absent. ARCHITECTURE.md's codegraph table is doc-sync guarded. Suite after the change: 475 pass / 5 live-gated; ruff + pyright clean.

## 0.1.0 (2026-10-18) — first standalone release

IntentGraph ships as its own product: persistent memory and retrieval intelligence for AI agents. One package (`intentgraph/`), MIT-licensed, local-first — the default configuration makes zero network calls.

**What's in the box**

- **Memory archive** — SQLite store with append-only version history, soft delete, tombstones, export/import; typed edges (`derived_from`, `caused_by`, `validated_by`, `supersedes`, `contradicts`, …), each explicit or inferred with its recorded basis; MinHash near-duplicate linking (deterministic across processes); auto-links for record ids mentioned in content.
- **Retrieval** — exact-id, BM25 lexical (identifier-aware tokenization), optional semantic (remote embeddings), and graph expansion over typed memory edges, fused with weighted RRF; plus the adaptive engine: question → evidence-requirements analysis → iterative gap-targeted retrieval → verification → token-budgeted evidence packet with an explicit `sufficient`/`partial`/`insufficient` verdict. Contradictions surface both sides; superseded records keep their successor named; missing evidence is reported, never fabricated.
- **Four surfaces** — SDK, CLI (`intentgraph`), local HTTP API (stdlib-only), and MCP agent tools (`intentgraph-mcp`: `remember`, `recall`, `context`, `feedback` — with server-injected usage instructions, project-scoped archives, per-call errors that never kill the process, mcp 1.x/2.x dual-compat).
- **Providers (all opt-in, credentials via gitignored `.env`)** — Nebius Token Factory and NVIDIA NIM embeddings behind one client (model discovery, dimension validation, stale-model detection forcing reindex, vector spaces keyed by provider+model+endpoint and never mixed), an LLM planning-policy interface with deterministic fallback, a reranker interface, and selective Tavily web search whose results carry full provenance and are never user memories. `privacy.local_only: true` refuses every remote provider class at configuration load.
- **Visualization** — the real archive as a self-contained interactive `graph.html`: memory-type communities, evidence panel, retrieval highlight/dim/reset driven by a REAL retrieve() call (cyan = direct, violet = graph-expanded), honest empty states, `</`-escaped JSON and sanitized fields at the renderer boundary.
- **Code-graph bridge (data-only)** — records with `graph_anchors` link into a `graph.json` file when one exists, so recall can follow code structure; bounded, deterministic, degrades to "no code-adjacency" honestly.
- **Benchmarks** — deterministic, reproducible, honestly labeled (`intentgraph benchmark`, `--agent`, `--providers`): pipeline recall, fresh-session recovery, selectivity, and provider latency.

**Provenance**

IntentGraph was developed in five phases (memory core, MCP integration, remote providers, visualization, engine decoupling) inside a fork of Graphify, then decoupled to zero engine imports and split out. This repository's earlier revisions distributed that Apache-2.0-licensed graph engine; it has been removed from the tree — see NOTICE for the provenance statement and git history for the record.
